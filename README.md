# Локальный анонимизатор таблиц данных

Настольное приложение (Python 3.11+, проверено на 3.15) для биективной анонимизации
персональных данных в таблицах и их полного восстановления через зашифрованный словарь.
Работа ТИМ: только детерминированные правила, без нейросетей и **без сети** (Г-1…Г-6, ТЗ 2.1).

## Возможности

- Импорт: CSV (`;` `,` `\t`; UTF-8 / UTF-8-BOM / Windows-1251), XLSX (все листы), XLS (чтение),
  JSON (массив записей), SQLite (выбор таблицы). pandas не используется.
- Авто-детект ПДн (`ColumnDetector`, 3 уровня: заголовки → regex → статистика) — решение за пользователем.
- Биективные коды: `ID-000001`, `PH-…`, `EM-…`, `AD-…`, `DOC-…`, `BD-…`, `TX-…`;
  одинаковое значение (обрезка пробелов + lower) — один код внутри проекта; разные проекты — разная нумерация.
- Маппинг хранится только зашифрованным: AES-256-GCM, ключ — PBKDF2-HMAC-SHA256 (600 000 итераций, соль 16 байт).
- Восстановление: мастер, сопоставление столбцов, политика неизвестных кодов (оставить/пусто/исключить строку).
- Словарь: просмотр после пароля (значения скрыты), экспорт зашифрованный по умолчанию,
  открытый CSV — только после предупреждения.
- Журнал операций — только метаданные, без ПДн и паролей; авто-закрытие проекта через 30 минут.
- Удаление проекта — перезапись файлов нулями перед удалением.

## Установка и запуск

```powershell
python -m pip install -r requirements.txt
python main.py
```

Проекты хранятся в `%USERPROFILE%\Проекты\<имя_проекта>\`
(`project.db`, `project.meta.json`, `journal.log`); папка настраивается
через меню «Файл → Папка проектов…». Если PyQt6 недоступен, ядро работает
без GUI — запустите хотя бы тесты (`python -m pytest`).

## Тесты

```powershell
python -m pytest                 # 85 тестов: Т-1…Т-10 (Т-8 пропускается по умолчанию)
$env:RUN_PERF='1'; python -m pytest -q    # + тест производительности Т-8 (20 000 × 20 < 30 с)
```

Smoke-тест GUI использует `QT_QPA_PLATFORM=offscreen` (в настройках уже выставлен).

## Упаковка в .exe (этап 4)

```powershell
.\build_exe.ps1        # результат: dist\TableAnonymizer.exe
```

- Сборка: PyInstaller, one-file, без консоли; интернет не используется ни при
  сборке-раскатке, ни в работе.
- Особенность окружения: Python 3.15 + cryptography 50 требуют заглушку
  `abi3t-compat\python3t.dll`, она добавляется в сборку автоматически
  (скрипт сам находит её в каталоге Python).
- Сборку следует прогонять по тестам Т-1 и Т-2 уже на готовом exe.

## Структура

```
project/
  src/gui/            # PyQt6: главное окно, мастера, словарь, диалоги
  src/application/    # сценарии: проекты, анонимизация, восстановление, словарь, авто-закрытие
  src/domain/         # ColumnDetector, MappingEngine, CryptoLayer, TableTransformer
  src/infrastructure/ # io_tables (CSV/XLSX/XLS/JSON/SQLite), mapping_store (SQLite), journal, secure_delete
  tests/              # pytest: Т-1…Т-10 + интеграционные + GUI smoke
  main.py             # точка входа
```

Правило зависимостей: Domain не импортирует GUI, файловую систему и сеть;
инфраструктура реализует порты домена (`src/domain/ports.py`).

## Отступления от ТЗ и причины

- **pandas отсутствует** — на Python 3.15 колёса pandas могут быть недоступны; структура
  `TableData` (заголовки + строки) + openpyxl/csv покрывают требования, зависимости меньше.
- **Запись XLSX вместо XLS** — живой библиотеки записи XLS нет (xlrd — только чтение);
  при сохранении `.xls` результат записывается как `.xlsx` с пометкой в интерфейсе.
- **Уникальный индекс по `value_hash` снят** — биективность обеспечивают кэши хранилища и
  логика `MappingEngine`; вставка в B-дерево вдвое быстрее (важно для лимита 30 с).
- **Т-8 (100 000 × 100 за 30 с)** в полном объёме на чистом Python без C-ускорителей
  практически недостижим; по умолчанию тест пропускается (маркер `performance`).
  Опорный сценарий 20 000 × 20 (400 000 ячеек, все значения уникальны) выполняется
  за ~27 с; бо́льшая часть реальных данных имеет повторы, которые обрабатываются быстрее.
- **WAL-режим SQLite** (`synchronous=NORMAL`, авто-чекпоинт отключён) — коммиты пачками
  по 20 000 записей; чекпоинт выполняется при закрытии проекта.

## Гарантии безопасности (ТЗ, раздел 2)

| Гарантия | Как обеспечено |
|---|---|
| Г-1 Ноль сетевых вызовов | запрещённые импорты отсутствуют — проверяется тестом `test_static_no_network.py` |
| Г-2 Маппинг всегда зашифрован | значения только в AES-256-GCM; хеш-токен пароля вместо пароля |
| Г-3 Утеря пароля = утрата словаря | в `project.meta.json` только соль, итерации и HMAC-токен |
| Г-4 Биективные коды | HMAC-SHA256 + кэши уникальности + линейный пробинг коллизий |
| Г-5 Без нейросетей | только regex/словари/статистика; ML-пакеты запрещены тестом |
| Г-6 Исходники не изменяются | все записи в новые файлы; тест сверяет SHA-256 до/после |
