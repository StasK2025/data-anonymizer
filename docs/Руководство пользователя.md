# Руководство пользователя

## Назначение

«Локальный анонимизатор таблиц данных» заменяет персональные данные (ФИО, телефоны,
e-mail, адреса, номера документов, даты рождения и др.) в таблицах на обратимые
обезличенные коды (`ID-000001`, `PH-000042`…). Словарь соответствий хранится
зашифрованным и открывается только паролем. Приложение полностью работает офлайн.

## Быстрый старт

1. Запуск: `python main.py` (после `python -m pip install -r requirements.txt`).
2. «Файл → Создать проект…»: имя, пароль (≥ 8 символов). **Пароль запомнить невозможно** —
   при утере словарь утрачен безвозвратно.
3. «Инструменты → Импорт таблицы…» — мастер:
   - Шаг 1. Файл: выберите CSV/XLSX/XLS/JSON/SQLite (и лист/таблицу при необходимости).
   - Шаг 2. Предпросмотр: первые 50 строк.
   - Шаг 3. Столбцы и типы ПДн: авто-детект отмечает рекомендованные столбцы;
     подозрительные (⚠) не отмечаются автоматически — решение за вами.
   - Шаг 4. Итоги → «Анонимизировать»: результат сохраняется как `<имя>__anon.<расширение>`.
     Исходный файл не изменяется.
4. Работайте с анонимной таблицей в Excel/других программах; статистика — на вкладке
   «Статистика», журнал операций — на вкладке «Журнал».
5. «Инструменты → Восстановить из файла…»: проект и пароль → файл с кодами →
   сопоставление столбцов → политика неизвестных кодов (оставить / пусто / исключить
   строку) → «Восстановить» → `<имя>__restored.<расширение>`.

## Словарь соответствий

«Инструменты → Словарь соответствий…» (только при открытом проекте):
значения скрыты по умолчанию; «Показать значения» раскрывает ПДн.
Экспорт — зашифрованный (`.map.json`); открытый CSV доступен только после
диалога предупреждения «данные в открытом виде». Импорт словаря возможен из
зашифрованного экспорта того же проекта или из открытого CSV (с подтверждением).

## Безопасность

- Пароль хранится только как хеш PBKDF2-HMAC-SHA256 (600 000 итераций, соль 16 байт).
- Значения словаря шифруются AES-256-GCM; в открытом виде нигде не сохраняются.
- Проект автоматически закрывается после 30 минут бездействия — память очищается,
  требуется ввести пароль заново.
- Удаление проекта перезаписывает файлы нулями.
- Журнал содержит только метаданные (время, действие, файл, размеры) — без ПДн и паролей.
- Исходные файлы никогда не изменяются: все результаты пишутся в новые файлы.

## Ограничения

- Запись в формате XLS не поддерживается (библиотека xlrd только читает XLS) —
  результат сохраняется как `.xlsx` с пометкой.
- pandas не используется: большие таблицы обрабатываются средствами openpyxl/csv/sqlite3.
